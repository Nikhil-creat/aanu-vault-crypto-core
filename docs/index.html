How this stays zero-knowledge: your passphrase never leaves this browser and is never stored anywhere. It's run through PBKDF2 (600,000 iterations) to derive an AES-256 key, which encrypts every note and file with a fresh random IV before it touches IndexedDB. Files are read, encrypted, and stored as ciphertext blobs — decrypted back to a viewable file only in memory, only while your vault is unlocked.
